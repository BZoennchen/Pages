## Teaching concept

This repository contains the raw files for the preprint


A novel Concept for teaching Software Engineering with and despite AI
#todo find a better title.

The paper is about

* an **interactive website and open-source learning materials**
* a **novel teaching concept** (distinguishing types of knowledge)
* a **real application in a programming course** at Hochschule München

There is currently no empirical study, but I think it is suitable for others **sufficient for a first publication**.


The paper will:

* introduce the teaching concept
* explain the theoretical motivation
* describe the system and implementation
* present its use in teaching

The paper does not claim proven learning improvements. This is scope of another study that I will conduct as soon as ethical approval has been granted.
